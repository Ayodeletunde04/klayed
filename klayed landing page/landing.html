# Send an Omnichannel message with failover via Klayed API
curl -X POST https://api.klayed.com/v1/messages \
  -H "Authorization: Bearer kly_live_94829ad01b" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+2348149201928",
    "channels": ["whatsapp", "sms"],
    "message": {
      "template": "order_dispatched",
      "params": { "name": "Tunde", "order_id": "KL-9042" }
    },
    "failover_timeout_secs": 60
  }'
// Node.js SDK
import { Klayed } from '@klayed/sdk';

const klayed = new Klayed(process.env.KLAYED_API_KEY);

const dispatch = await klayed.messages.send({
  to: '+2348149201928',
  channels: ['whatsapp', 'sms'],
  content: {
    template: 'order_dispatched',
    params: { name: 'Tunde', orderId: 'KL-9042' }
  },
  failoverAfter: 60
});

console.log('Dispatched message ID:', dispatch.id);

Common questions

Frequently Asked Questions

Everything you need to know about getting started with Klayed.

What channels does Klayed support?

Klayed natively supports WhatsApp Business Cloud API, SMS (transactional, OTP, and promotional), Email campaigns, and Automated Voice (IVR & text-to-speech calls) — all orchestrated from a single dashboard and unified API.

How long does integration take?

Most developers send their first live test message in under 10 minutes. We provide plug-and-play SDKs for Node.js, Python, PHP, and Go, plus standard HTTP REST documentation and Postman collections.

Do you provide APIs?

Yes. Klayed is an API-first platform. Every single feature visible in our dashboard — including multi-channel dispatch, failover rules, template registration, subscriber management, and delivery analytics — is accessible via high-performance REST APIs and real-time Webhooks.

Can I automate campaigns?

Absolutely. You can build visual event-triggered drip sequences, recurring broadcasts, smart abandoned-cart recovery flows, and automatic cross-channel failovers (e.g. if a WhatsApp message is unread within 5 minutes, deliver an immediate SMS).

Is WhatsApp officially supported?

Yes. Klayed integrates directly with Meta's Official WhatsApp Cloud Business Solution. We facilitate official green-badge business verification, template approvals, and high-throughput broadcast limits without the risk of phone number bans.

Do you offer enterprise plans?

Yes. For companies sending over 500,000 messages monthly, we offer custom volume pricing discounts, dedicated IP warmup, guaranteed 99.99% SLAs, 24/7 priority engineering support, and bespoke on-premise carrier route interconnects.
